## Abrir en Visual Studio Code

1. Extrae el ZIP completo, conservando las carpetas.
2. En VS Code selecciona **Archivo > Abrir carpeta** y abre `portfolio_aldrin_ec2`.
3. Abre `index.html` en el navegador (doble clic en el archivo) o utiliza Live Server si ya lo tienes instalado.
4. Edita los textos en `index.html`, el diseño en `style.css` y los eventos en `script.js`.

## Publicar en GitHub Pages

1. Crea un repositorio público nuevo en GitHub.
2. Sube **el contenido de la carpeta** a la raíz del repositorio, incluyendo `index.html`, `style.css`, `script.js` y `imagenes/`.
3. En el repositorio entra a **Settings > Pages**.
4. Selecciona **Deploy from a branch**, rama `main`, carpeta `/(root)` y guarda.
5. GitHub mostrará la dirección pública cuando se complete la publicación.

**Atención:** publicar en GitHub Pages hará públicos los datos de contacto y fotografías incluidos. Revísalos antes de publicar.

## Contenidos de clase usados

- HTML: títulos, párrafos, imágenes, enlaces, listas de navegación, botones, secciones y atributos `id` y `class`.
- CSS: colores, tipografías, espacios, cuadrículas, adaptación a pantallas pequeñas.
- JavaScript: `const`, `let`, funciones, `if/else`, `for`, `getElementById`, `querySelectorAll` y `addEventListener`.

No usa frameworks, bases de datos, bibliotecas externas ni servicios de terceros.
